# ふーさんの もりびらき 〜5つのめぐみで村づくり〜

▶ **あそぶ: https://ryowatanabe1161-svg.github.io/moribiraki/**

村づくりボードゲーム。3〜4人。タイトルで遊び方を選べます。

- **1台であそぶ**：1台の端末をまわして遊ぶ（パス＆プレイ）。それぞれ「人」か「ふーさん🐻」（コンピュータ）を選べます
- **オンラインであそぶ**：部屋を作って招待URL・QR・部屋コードで最大4人。足りない席はふーさん🐻が入ります。自分の手札・ふしぎカードは自分の端末だけに表示、7のときは各自の端末で同時にすてる、交換の提案には各自の端末で返事。切断しても同じニックネームで入り直せば元の席に戻れます（それまではふーさんが代わりにプレイ）

- 森の島（19マス）で まるた🪵・ねんど🧱・わたげ🐑・こむぎ🌾・いわ🪨 を集めて、いえ🏠・やかた🏰・こみち🛤️ を作ろう
- サイコロ、いたずらアライグマ🦝、港・森のくらとの交換、みんなとの交換、ふしぎカード
- 先に10点になった人の勝ち（自分の番のときだけ）
- スマホ縦・PC対応。1台モードはオフラインで動作・自動セーブ

ファイル: `index.html` / `app.js`（画面・オンライン通信）/ `logic.js`（ルール・ふーさんAI）/ `config.js`（STUNサーバー設定）/ `vendor/`（PeerJS・QRコード）

オンラインは PeerJS（WebRTC P2P）で、ホストのブラウザがゲームを進行します（サーバー不要）。接続の仲介に PeerJS の公開シグナリングサーバー、NAT越えに公開STUNサーバーを使います（TURNなし。会社・学校などの厳しいネットワークではつながらないことがあります）。
